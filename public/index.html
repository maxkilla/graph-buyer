graph-buyer

FalkorDB graph agent · VIN in, pull verdicts out · teardown-parts MCP tooling

First run on a new vehicle can take up to ~60s — every price is looked up live. Re-runs hit graph memory and skip re-pricing.

How the graph works 
DonorCar ──HAS_PART──▶ Part ──HAS_PRICE_SIGNAL──▶ PriceSignal (live eBay)
   │                    ╰──LED_TO_DECISION──▶ Decision (PULL / SKIP)
   ╰──SIMILAR_TO──▶ DonorCar (same year/make/model — inherits outcomes)

Every run reads and writes this FalkorDB graph. Fresh PriceSignals are reused — no repeat searches. Shared Part nodes show which other donors carry the same part.
